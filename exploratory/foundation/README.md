# Foundation

## Purpose

This folder contains early conceptual framing, motivation, and philosophical background for CrypSA.

These documents help explain:

* why CrypSA exists
* the problems it was designed to address
* the evolution of the architecture

---

## Important

Documents in this folder are **not authoritative**.

They:

* do not define the current architecture
* do not define system behavior
* may contain outdated terminology or models

They must not be treated as:

* architecture definitions
* specification rules
* implementation guidance

---

## Source of Truth

For the current CrypSA model, refer to:

## Consistency Rules

Documents in this folder must not:

* redefine core architectural concepts
* introduce conflicting terminology
* override definitions in `architecture/` or `spec/`

If a conflict exists:

> the authoritative sources always take precedence

## Evolution

This folder captures the early thinking and conceptual development of CrypSA.

If ideas from these documents become stable, they should be:

1. refined
2. aligned with current terminology

   * `architecture/` (structure)
