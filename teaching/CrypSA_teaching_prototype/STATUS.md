# CrypSA Teaching Prototype Status

## Status

This project is a completed teaching prototype for the CrypSA model.

It should be treated as:

- a finished teaching artifact
- a stable demonstration of the CrypSA model
- the educational front door for understanding the local-vs-canonical split

It should not be treated as:

- a production runtime
- a reference server
- a distributed implementation
- the main place where future runtime experiments will continue

## Completion Scope

This prototype is considered complete for its intended purpose:

- teaching candidate events at the invariant boundary
- teaching canonical validation and reconciliation
- teaching accepted canonical history as the substrate of truth
- teaching replay-derived canonical state
- teaching branching and historical selection through History and Timeline
- teaching Mint-authored definitions as structural input to canonical objects

## Change Policy

This artifact is effectively frozen except for:

- critical bug fixes
- doc corrections
- small packaging or status clarifications

It is not intended to remain an open-ended architecture playground.

## Future Work

If future CrypSA work needs to explore new questions, it should usually happen in a separate program or prototype.

Examples:

- independent server runtime work
- multi-observer or networked behavior
- conflict or divergence-heavy experiments
- runtime-proof or deployment-oriented experiments

Those should not be forced back into this teaching artifact unless there is a very strong reason.

## One Sentence Summary

This repository is a completed teaching prototype for the CrypSA model and should be maintained as a stable educational artifact rather than continuously expanded into the future runtime path.
