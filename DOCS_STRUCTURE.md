## Rule

If multiple documents appear to describe the same concept, the sections above take precedence.

Supporting and exploratory documents should not be treated as authoritative definitions of current CrypSA behavior.

If two documents describe the same concept at the same level, one must be demoted.

No duplicate authoritative explanations are allowed.
