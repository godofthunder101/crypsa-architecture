# CrypSA Specification Versioning

This document defines how CrypSA specifications are versioned.

---

## Current Version

CrypSA Runtime Specification:

> v0.1

---

## Version Meaning

### v0.x — Experimental

- concepts are stabilizing  
- breaking changes are expected  
- not production-ready  

---

### v1.0 — Stable Runtime

- core runtime model finalized  
- backward compatibility begins  
- suitable for production use  

---

## Version Scope

Versioning applies to:

- runtime behavior  
- event structure  
- validation rules  
- consistency guarantees  
- identity model  
- transport expectations  

---

## Change Policy (v0.x)

During v0.x:

- breaking changes are allowed  
- specs may evolve rapidly  
- documents should remain internally consistent  

---

## Future Direction

Future versions may include:

- formal compatibility guarantees  
- migration paths between versions  
- protocol-level version negotiation  

---

## One Sentence Summary

CrypSA v0.1 is an experimental specification defining the initial runtime model, with evolution expected before stability.
